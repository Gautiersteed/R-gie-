⏱️ Horaires prévus du direct

Pas de démarrage ou d’arrêt automatique à heure fixe. Cette page modifie les horaires annoncés d’un direct existant dont vous êtes propriétaire. Elle ne crée pas de direct et n’envoie aucun flux vidéo. Démarrez et terminez la diffusion depuis votre encodeur et YouTube Studio. Les options de démarrage/arrêt automatiques de YouTube dépendent du flux reçu, pas simplement de ces dates.

Système : prêt.
Mode d’emploi et limites
  1. Pour le lecteur, indiquez un ID ou un lien YouTube et cliquez sur le bouton rouge. L’intégration doit être autorisée par le propriétaire ; certaines vidéos ne peuvent pas être intégrées.
  2. Pour la connexion et la programmation, hébergez ce fichier sur une origine HTTPS, par exemple votre GitHub Pages. Une ouverture locale en file:// permet de voir l’interface, mais n’est pas adaptée à OAuth ni au chat intégré.
  3. Dans Google Cloud, activez YouTube Data API v3, configurez l’écran de consentement et créez un client OAuth de type Application Web. Ajoutez l’origine exacte de votre site aux Origines JavaScript autorisées, par exemple https://gautiersteed.github.io (sans chemin ni barre finale). Si l’application est en test, ajoutez votre compte aux utilisateurs test. Google peut imposer une vérification pour une diffusion publique de l’application.
  4. Collez seulement l’ID client public, jamais un secret client. Connectez le compte qui possède le direct et autorisez la gestion YouTube. La connexion Gmail n’est pas nécessaire.
  5. Créez d’abord votre direct dans YouTube Studio, puis utilisez son ID ici. « Vérifier mon direct » consulte son état sans modifier YouTube. L’enregistrement demande confirmation et conserve le titre, la description et la catégorie existants ; il ne change pas la confidentialité.
  6. Le domaine du chat doit être le domaine réel de cette page. Le chat peut rester indisponible pour une rediffusion, un direct privé, du contenu destiné aux enfants, ou si YouTube le désactive. Pour écrire, ouvrez YouTube si la connexion ne fonctionne pas dans l’iframe.
  7. Vos champs sont mémorisés dans ce navigateur lorsque le stockage est autorisé. Le jeton Google reste uniquement en mémoire et expire ; reconnectez-vous si nécessaire. Aucune action n’est exécutée en arrière-plan lorsque la page est fermée.
